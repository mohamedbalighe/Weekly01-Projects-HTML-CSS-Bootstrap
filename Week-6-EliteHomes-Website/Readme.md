# EliteHomes - Modern Real Estate Landing Page 🏠

EliteHomes is a premium, fully responsive real estate landing page built as part of the **Bootstrap 5** certification. The project focuses on clean UI/UX, modern design trends like soft shadows and gradients, and a seamless interactive experience.

## ✨ Key Features

* **Interactive Services Tabs:** A dynamic tab system allowing users to switch between services (Buying, Selling, Renting, Investing, and Commercial) with custom-styled icons.
* **Comprehensive Contact Section:** A unified section featuring quick-action contact cards, detailed company information, and a professional inquiry form.
* **Advanced Form Elements:** Includes a custom-styled dropdown menu with specific real estate service options.
* **Fully Responsive Design:** Optimized for all screen sizes (Mobile, Tablet, Desktop) using the Bootstrap 12-column grid system.
* **Modern Visuals:** High-quality imagery, CSS-driven linear gradients, and interactive hover effects on cards and buttons.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for SEO and accessibility.
* **CSS3:** Custom styling for gradients, soft backgrounds, and layout refinements.
* **Bootstrap 5:** Core framework for layout, navigation, and responsiveness.
* **Font Awesome 6:** Comprehensive icon set for social media and utility icons.
* **Vercel/GitHub Pages:** Deployed for live preview.

## 📸 Project Structure

### 1. Hero & Navigation
A clean navbar with active link states and a professional branding area.

### 2. Services Section
Dynamic content area that changes based on the selected real estate category.

### 3. Integrated Contact Hub
Combines "Get In Touch" cards with a "Send us a Message" form into a single, cohesive user experience.

### 4. Footer
A deep purple, high-contrast footer containing copyright info, social links, and a signature tagline.
