# 🏋️‍♂️ FitCore Gym - Premium Landing Page
A modern, high-conversion landing page for a fitness facility. This project demonstrates advanced layout techniques using **CSS Float** and **Clearfix** to create a responsive and professional user experience.

### 🎯 Project Overview
The goal was to build a multi-section landing page that includes complex components like grids, testimonial cards, and a membership registration form, all while maintaining a clean and consistent design language.

## 🚀 Live Demo
[View](https://mohamedbalighe.github.io/Weekly01-Projects-HTML-CSS-Bootstrap/Week-2-FitCore-Gym-Landing/index.html)

### 🛠 Technical Skills Applied
* **CSS Layouts (Floats):** Mastering the use of `float: left/right` to build multi-column layouts.
* **Clearfix Hack:** Implementing `clearfix` classes to prevent parent container collapse in floated layouts.
* **External Styling:** Managing large-scale CSS in an independent file (`styling.css`).
* **Typography:** Integrating **Google Fonts (Inter)** for a modern, readable aesthetic.
* **Form Design:** Creating a clean, user-friendly registration form with custom styling for inputs, selects, and textareas.
* **Component Building:** * **Hero Section:** High-impact call-to-action area.
    * **Feature Cards:** Color-coded cards for service highlights.
    * **Testimonials:** User feedback section with custom avatar styling.
    * **Stats Bar:** A dark-themed impact section using percentages and large numbers.

### 📦 Key Features
* **Clean Architecture:** Semantic HTML5 tags for better SEO and accessibility.
* **Styling Consistency:** Global reset and unified color palette (`#1a202c`, `#f7fafc`).
* **Professional Footer:** Organized with brand identity, quick links, and contact info.
