# The UX Review - Brutalist Web Design

## 🚀 Live Demo
[View](https://mohamedbalighe.github.io/Weekly01-Projects-HTML-CSS-Bootstrap/Week-4-The-UX-Review-Blog-Landing/index.html)

## ✨ Features
- **Brutalist Aesthetic:** Heavy borders, high-contrast colors (yellow, red, blue), and thick shadows.
- **Responsive Layout:** Designed to work across different screen sizes using CSS Flexbox.
- **Sticky Navigation & Sidebar:** Enhanced user experience for long-form content.
- **Hover Effects:** Interactive buttons and cards with "pop" animations.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling, Flexbox, and CSS transitions.
- **FontAwesome:** For the bold, descriptive iconography.
- **Google Fonts:** Using the 'Inter' typeface for a modern look.

## 📂 Project Structure
- `index.html` - The main structure of the page.
- `css/style.css` - All the brutalist styling logic.
- `Images/` - Directory containing article thumbnails and author avatars.
