# 🚀 Project 01: The Foundation Portfolio
This is my very first Frontend Assignment. It represents the starting point of my journey, where I focused on mastering the core structure of web pages using **Pure HTML** and **Embedded CSS**.

### 🎯 Assignment Goals
The main challenge was to build a complete, organized portfolio page using **HTML Tables** for the layout, ensuring a structured presentation of data without relying on advanced frameworks.

### 🛠 Skills Demonstrated
* **Table-based Layouts:** Using `<table>`, `<tr>`, and `<td>` to create a structured grid.
* **Complex Table Features:** Implementing `rowspan` and `colspan` in the Experience Timeline.
* **HTML Forms:** Building a full contact section with `fieldset`, `legend`, and various `input` types.
* **CSS Styling:** * Using **Box Shadows** and **Border Radius**.
    * Embedded styling using the `<style>` tag.
    * Customizing typography and background aesthetics.

### 📦 Page Sections
1.  **Header:** Professional title and sub-headline.
2.  **About Me:** A split-cell layout containing a profile image, social icons, and a brief bio.
3.  **Experience Timeline:** A detailed table showcasing professional history with achievement lists.
4.  **Contact Form:** A user-friendly form organized into "Personal Information" and "Project Details".
