# 🎮 GameArena - Ultimate Gaming Platform

GameArena is a modern, responsive gaming landing page built with **Bootstrap 5**. The project features sections for the latest games, services (what we do), team members, and a professional contact form.

## 🚀 Live Demo
[Check it out here](https://mohamedbalighe.github.io/Weekly01-Projects-HTML-CSS-Bootstrap/Week-5-GameArena-Website/index.html) 

## ✨ Key Features
- **Modern Dark Theme:** Custom aesthetic using `#0b0e13` and neon yellow `#cbfe1c`.
- **Responsive Navigation:** Sticky Bootstrap navbar with customized toggler.
- **Interactive Game Cards:** Hover effects with scaling images and content sliding.
- **Service Highlights:** Custom-designed cards with dynamic corner accents using CSS pseudo-elements.
- **Team Showcase:** Character-based cards with vertical text layouts and grayscale filters.
- **Integrated Contact Form:** Clean, validated UI with custom form styling.

## 🛠️ Built With
- **HTML5:** Semantic markup.
- **CSS3:** Custom properties, Flexbox, Transitions, and `clip-path` for creative shapes.
- **Bootstrap 5:** Grid system, components (Navbar, Buttons, Forms).
- **FontAwesome:** Pro-grade gaming and social icons.
- **Google Fonts:** 'Kanit' for a bold, heavy-weight typography.

## 📂 Project Structure
- `index.html` - Full page layout.
- `css/styling.css` - Custom styling and design logic.
- `js/bootstrap.bundle.min.js` - Bootstrap interaction scripts.
- `images/` - Optimized gaming assets (heroes, avatars, game thumbnails).
